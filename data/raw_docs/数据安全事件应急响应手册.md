# 数据安全事件应急响应手册

## 1. 事件分级

- P1（重大）：核心生产数据泄露、大规模勒索加密、被监管机构通报；
- P2（严重）：单一系统数据泄露、敏感数据异常外发；
- P3（一般）：内部违规操作、病毒感染但未扩散；
- P4（轻微）：钓鱼邮件、可疑扫描行为。

## 2. 响应时限

- P1 事件：15 分钟内启动响应，1 小时内上报公司安全委员会；
- P2 事件：30 分钟内启动响应，4 小时内完成初步定性；
- P3/P4 事件：2 小时内响应，当日处置完毕。

## 3. 标准处置流程

处置按五步执行：发现与确认 → 遏制（断网隔离、封禁账号）→ 根除 → 恢复 → 复盘。

- P1/P2 事件处置完成后 5 个工作日内提交复盘报告；
- 每次复盘必须输出至少一条可落地的改进措施，并纳入下季度安全检查项；
- 未经安全部门同意，任何个人不得对外披露事件细节。
