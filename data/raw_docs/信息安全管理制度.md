# 公司信息安全管理制度（试行 V3.2）

## 1. 账号与密码

- 所有内部系统密码长度不得少于 12 位，必须同时包含大写字母、小写字母、数字和特殊符号。
- 密码有效期 90 天，到期强制更换；禁止复用最近 5 次使用过的历史密码。
- 连续 5 次输错密码，账号自动锁定 30 分钟。
- 禁止在代码、文档、聊天工具中明文出现密码和 API Key。

## 2. 权限管理

- 遵循最小权限原则：员工默认只开通岗位所需的系统权限。
- 涉及生产数据查询的权限，必须由部门负责人和数据安全员双重审批后开通。
- 权限每季度复核一次，连续 90 天未使用的权限自动回收。
- 离职员工账号在最后一个工作日 24:00 前必须注销，归还所有办公系统访问凭证。

## 3. 数据分级

公司数据按敏感程度分为四级：

1. 公开级：可对外发布的产品资料、招聘信息；
2. 内部级：日常办公文档、内部通知、周报；
3. 敏感级：客户联系方式、订单数据、员工个人信息；
4. 机密级：源代码、安全策略、密钥证书、未公开财务数据。

敏感级及以上数据外发必须先脱敏或加密，并通过 OA 流程审批；机密级数据禁止通过即时通讯工具传输。

## 4. 办公终端要求

- 办公电脑必须安装终端安全客户端并开启全盘加密。
- 禁止使用个人网盘、个人邮箱存储或传输内部级以上数据。
- 违反本制度的，按《信息安全违规处理办法》第 8 条处理，情节严重的解除劳动合同。
