# AI 产品研发流程规范（2026 修订版）

## 1. 研发阶段

AI 产品研发按以下五个阶段推进：

1. 需求评审：产品经理输出 PRD，评审通过后冻结需求范围；
2. 方案设计：算法或应用工程师输出技术方案，内容包括模型选型、评估指标、Token 成本预估；
3. 开发与自测：代码合并需通过单元测试覆盖率不低于 60% 的门禁；
4. 测试验收：执行功能测试与效果评估，问答类产品要求回答准确率不低于 90% 方可发布；
5. 灰度发布：新功能先对 5% 用户放量，观察 72 小时无 P1/P2 级问题后全量上线。

## 2. 大模型应用专项要求

- 所有调用外部大模型 API 的应用，上线前必须完成提示注入测试与输出内容合规抽检，抽检比例不低于 500 条对话样本。
- 用户输入与模型输出日志留存不少于 180 天，用于安全审计与效果回归。
- 涉及用户个人信息的场景，数据进入模型前必须完成 PII 脱敏，脱敏率要求 100%。
- 生产环境的模型、温度等参数变更需走变更审批，禁止临时手工调整。

## 3. 版本与回滚

- 生产发布必须提供可在 1 分钟内执行完成的回滚方案，回滚预案未经演练不得上线。
- Prompt 属于代码资产，纳入 Git 统一管理，每次修改必须有对应的评测报告。
- 线上事故按《数据安全事件应急响应手册》定级，P1/P2 事故 5 个工作日内完成复盘。
